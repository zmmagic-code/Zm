# Link Hub

A minimal, mobile-friendly personal link hub built with React, Vite, and Tailwind CSS.

## What's inside

- Profile section: avatar (initials in a vinyl-style gold ring), name, role, and a short bio
- 4 clickable links, each opening in a new tab, with a hover accent and external-link cue
- Dark theme: warm charcoal background, off-white text, gold accent
- Fully responsive, single-column layout that works down to small phone widths

## Customize it

Edit `src/App.jsx`:

- `profile` — update name, role, bio, and initials
- `links` — update each link's label, detail line, and href (all open in a new tab automatically)

Colors and fonts live in `tailwind.config.js` under `theme.extend`.

## Run it locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```
